# 📊 E-Commerce Sales Analytics Dashboard

## 1. Project Title / Headline

### 📈 Interactive E-Commerce Sales Analytics Dashboard using Power BI

An end-to-end Business Intelligence dashboard built in **Microsoft Power BI** to analyze E-Commerce sales performance, profitability, customer purchasing trends, and regional insights through interactive visualizations.

---

# 2. Project Description / Purpose

The **E-Commerce Sales Analytics Dashboard** is a dynamic Power BI report developed to transform raw sales data into actionable business insights. It enables users to monitor key business metrics, evaluate sales performance across different states, analyze monthly profit trends, compare product categories, and understand customer payment preferences.

The dashboard is designed to support business stakeholders in making informed, data-driven decisions through intuitive and interactive visualizations.

---

# 3. Tech Stack

The dashboard was developed using the following technologies:

* 📊 **Microsoft Power BI** – Interactive dashboard development and data visualization.
* 🔄 **Power Query** – Data cleaning, transformation, and preparation.
* 📐 **DAX (Data Analysis Expressions)** – Business calculations, measures, and KPIs.
* 🔗 **Data Modeling** – Creating relationships between multiple datasets.
* 📄 **CSV Dataset** – E-Commerce sales transaction data.

---

# 4. Dashboard Features

### 📅 Quarter-wise Analysis

Analyze sales performance across different quarters using interactive buttons.

### 📍 State-wise Sales Analysis

Compare sales generated from different states.

### 💰 Monthly Profit Analysis

Track monthly profit trends and identify profitable as well as loss-making periods.

### 💳 Payment Mode Distribution

Visualize customer payment preferences across multiple payment methods.

### 📦 Category-wise Quantity Analysis

Analyze the quantity of products sold across different categories.

### 📈 Sub-Category Profit Analysis

Identify the most profitable product sub-categories.

### 🎯 Interactive Filters & Slicers

Enable dynamic filtering for enhanced business analysis.
